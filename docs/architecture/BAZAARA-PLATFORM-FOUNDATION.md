# BAZAARA Platform Foundation

Permanent repository name: bazaara-platform

Build order:
1. Ecosystem 1 — Commerce & Everyday Life
2. Ecosystem 2 — Social, Media & Communication
3. Ecosystem 3 — Intelligence, Productivity & Infrastructure

Shared platform foundations:
- BazID — identity
- Wallet — money and ledger
- Operations — internal platform control
- GO — delivery/courier execution
- Support — shared case and escalation system
- Notifications — shared delivery layer
- Security/Risk — shared trust controls
- Analytics — shared event taxonomy
- Design System — shared product language

BazID / Bmail foundation:
- BazID should recommend a matching @bmail.com address during account creation.
- Example: username "daniel" -> suggested address "daniel@bmail.com".
- Bmail mailbox functionality is NOT being built yet.
- The foundation should reserve/link the address namespace so Bmail can activate it later.
- If the requested address is unavailable, BazID should recommend alternatives and let the user choose.

Naming:
- Do not prefix app names with "Bazaara" unless the product's canonical name explicitly includes it.
- Canonical Ecosystem 1 names include Wallet, not "Wallet".
